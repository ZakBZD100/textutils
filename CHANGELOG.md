# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-09-17

### Added

- `snake_case()` function to convert text to snake_case
- `camel_case()` function to convert text to camelCase
- `slugify()` function to generate URL-friendly slugs

### Changed

- Refactored Session 1 code with type hints and full docstrings
- Improved test coverage with edge case tests (47 tests total)

## [0.1.0] - 2026-09-15

### Added

- `word_count()` function to count words in a text
- `character_count()` function to count characters in a text
- `reverse()` function to reverse a text string
- `capitalize_words()` function to capitalize each word in a text
- Unit tests for all functions
- MIT License
- README with documentation and usage examples
- GitHub Actions CI workflow
