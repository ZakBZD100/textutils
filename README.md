# textutils

a small python library for text operations

## Features

- word counting
- character counting
- text reversal
- capitalize words

## Installation

```bash
pip install textutils
```

## Usage

```python
from textutils import word_count

count = word_count("Hello Open Source!")
print(count) #2
```
